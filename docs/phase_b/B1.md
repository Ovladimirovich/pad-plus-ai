# B1 — Typed Sections для PipelineContext

## Цель
Заменить неструктурированный `context: Dict[str, Any]` на типизированные именованные секции, обеспечив автокомплит, валидацию на уровне IDE и обратную совместимость.

## Что сделано

### 1. TypedDict-секции (`context.py`)
Добавлены 5 секций с `total=False` (каждое поле опционально):

| Секция | Назначение | Ключи |
|--------|-----------|-------|
| `MemorySection` | Все данные памяти | `episodic_context`, `semantic_context`, `rag_results`, `persona_traits`, `user_persona_traits`, `roots_context`, `persona_summary`, `consolidation_context`, `knowledge_graph_context`, `memory_maintenance` |
| `EmotionSection` | Эмоциональное состояние | `current_emotion`, `current_mood`, `emotion_style` |
| `ImpulseSection` | Импульсы/желания | `impulse_primary`, `impulse_labels`, `impulse_state` |
| `StrategySection` | Стратегия ответа | `intent_classification`, `response`, `confidence`, `rag_status`, `generation_strategy`, `procedure_hint`, `procedure_results` |
| `ControlSection` | Управляющие данные | `safety_check`, `anti_loop_decision`, `reflection_cycle`, `dream_context`, `evaluation_feedback`, `metrics_data`, `extracted_concepts`, `extracted_relations`, `broadcast_events`, `response_guard_result` |

### 2. Маршрутизация `_CONTEXT_KEY_MAPPING`
Словарь, мапящий 30+ строковых ключей (как они записывались в `ctx.context["key"]`) в соответствующие секции. Используется в `update_context()`.

### 3. `PipelineContext.update_context(data)`
Единая точка записи:
- Пишет в `self.context[key]` (обратная совместимость)
- Определяет целевую секцию через `_CONTEXT_KEY_MAPPING` → пишет в неё
- Если ключ не найден в маппинге — пишет только в `self.context` (без ошибки)

### 4. `PipelineContext.to_background_snapshot()`
Автоматически собирает `bg_data` для background-фаз, исключая ephemeral-ключи (events, streams, callback data).
