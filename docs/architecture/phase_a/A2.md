# A2: Align `procedure_used` Key Name Between SemanticPhase and SaveEpisodePhase

## Проблема

SemanticPhase пишет в `ctx.context` ключ `procedure_name`, но SaveEpisodePhase читает ключ `procedure_used`. В результате ветка `if procedure_used:` в SaveEpisodePhase **никогда не срабатывает**.

**Файл:** `backend/core/pipeline/phases/save_episode.py`, строка ~23:
```python
procedure_used = ctx.context.get("procedure_used")  # Всегда None
```

**Файл:** `backend/core/pipeline/phases/semantic.py` — пишет:
```python
data = {
    "procedure_context": procedure_context,
    "procedure_name": procedure_name,  # <-- Этот ключ
    "procedure_id": procedure_id,
}
```

## Причина

Историческое расхождение имён. SemanticPhase был переименован, но SaveEpisodePhase не обновлён.

## Решение

Изменить чтение в `save_episode.py` с `procedure_used` на `procedure_name`, либо писать оба ключа в semantic.py.

### Вариант A (рекомендуемый)

Изменить `save_episode.py`:

```python
# Было:
procedure_used = ctx.context.get("procedure_used")

# Стало:
procedure_used = ctx.context.get("procedure_name")
```

### Вариант B (совместимость)

Добавить в `semantic.py`:
```python
data = {
    "procedure_context": procedure_context,
    "procedure_name": procedure_name,
    "procedure_id": procedure_id,
    "procedure_used": procedure_name,  # <-- Алиас для обратной совместимости
}
```

**Рекомендуется Вариант A**, так как он устраняет корень проблемы, а не маскирует её.

## Тест

**Существующий тест:** `tests/test_pipeline/test_save_episode.py`
- `test_save_episode_success` — проверяет, что эпизод сохраняется. Сейчас significance bonus за procedure не срабатывает. После фикса significance должен увеличиваться при наличии procedure.

**Новый тест:** Добавить проверку, что наличие procedure_name увеличивает significance:

```python
async def test_save_episode_significance_boost_from_procedure():
    mock_episode = MagicMock()
    mock_episode.id = "ep_123"

    with patch("memory.get_episodic_memory") as mock_get:
        mock_mem = MagicMock()
        mock_mem.add_episode.return_value = mock_episode
        mock_get.return_value = mock_mem

        phase = SaveEpisodePhase()
        ctx = PipelineContext(
            user_message="test",
            context={
                "response": "ok",
                "intent": "chat_general",
                "rag_used": False,
                "procedure_name": "Обработка запроса",  # <-- Исправленный ключ
                "truth_confidence": 0.8,
                "emotion_state": {"уверенность": 0.7},
            },
        )
        result = await phase.execute(ctx)

    assert result.success
    # Проверяем, что add_episode был вызван с significance ≥ 0.65
    # (базовое 0.5 + 0.15 за procedure)
```

## Результат

| До | После |
|----|-------|
| `procedure_used` всегда None | `procedure_name` читается корректно |
| Significance bonus за процедуру никогда не применяется | Significance учитывает наличие процедуры |
| Мёртвая ветка кода | Ветка активно используется |
