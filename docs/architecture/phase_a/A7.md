# A7: Remove Dead Code — `_topic_stats`, `_history`, `ImpulseState` DTO

## Проблема

Аудит выявил три компонента мёртвого кода:

| Компонент | Файл | Статус |
|-----------|------|--------|
| `RAGMemory._topic_stats` | `memory/rag.py` | Инициализируется, никогда не пишется и не читается |
| `Consolidator._history` | `memory/consolidation.py` | Только append, никогда не экспортируется, теряется при рестарте |
| `ImpulseState` DTO | `impulse/*.py` | Определён, экспортирован, никогда не инстанциирован |

## Причина

Каждый компонент — остаток рефакторинга:
- `_topic_stats` был заменён на `frequent_topics` в `UserPersona`
- `_history` был заменён на `get_consolidation_stats()` (но `_history` остался как поле)
- `ImpulseState` был заменён на in-memory dict

## Решение

### A7.1: Удалить `_topic_stats` из RAGMemory

```python
# В memory/rag.py — удалить:
self._topic_stats: Dict[str, int] = {}
# И все упоминания в методах (get_topic_stats, update_topic_stats, etc.)
```

### A7.2: Ограничить `Consolidator._history` (Option B)

**Реализован Option B:** `_history` оставлен как внутреннее поле, но с лимитом (`_max_history = 100`). При каждом append (все 4 места записи) список обрезается до `_max_history`.

**Вариант A (удалить)** был отклонён, потому что `_history` используется для диагностики (health check, отладка pipeline).

### A7.3: Удалить `ImpulseState` DTO

Найти файл с определением `ImpulseState` и удалить класс. Проверить импорты.

```bash
# Поиск по проекту:
grep -r "ImpulseState" --include="*.py"
```

Если не используется — удалить класс и импорт.

## Тест

**Новый тест:**

```python
async def test_no_dead_code_imports():
    """Проверяет, что мёртвый код не импортируется."""
    # ImpulseState не должен быть импортирован нигде
    import sys
    assert "ImpulseState" not in sys.modules, "ImpulseState всё ещё импортируется"
```

**Регрессионный тест:** Все существующие тесты должны проходить. Удаление мёртвого кода не должно вызывать ошибок импорта.

## Результат

| До | После |
|----|-------|
| `_topic_stats` занимает память и never used | Память не выделяется |
| `_history` растёт бесконечно и теряется | История или удалена, или явно управляется |
| `ImpulseState` — мёртвый DTO | Код удалён |
| Импорт неиспользуемых классов | Чистые импорты |
