# A3: Write `result_dict` Before ReflectionPhase Reads It

## Проблема

ReflectionPhase читает `ctx.context.get("result_dict", {})` и передаёт в `system_state_manager.update()`. Но **ни одна фаза не пишет** `result_dict` в context. Всегда передаётся пустой словарь.

**Файл:** `backend/core/pipeline/phases/reflection.py`, строка ~22:
```python
state_manager.update(ctx.context.get("result_dict", {}))
```

## Причина

`result_dict` — это устаревший концепт. Ранее pipeline возвращал `dict`, теперь он возвращает `PipelineResult`. ReflectionPhase не была обновлена.

## Решение

В `executor.py`, перед запуском background-фаз, записать основные поля `PipelineResult` в `ctx.context` под ключом `result_dict`.

### Конкретные изменения

В `executor.py`, в методе `execute()`, после строки:
```python
if result.success and result.response.strip():
    self._fire_background_phases(ctx, result, request_id, start_time)
```

**Добавить перед** `_fire_background_phases`:
```python
# Запись result_dict для background-фаз (reflection и др.)
ctx.context["result_dict"] = {
    "success": result.success,
    "response": result.response,
    "intent": result.intent,
    "strategy": result.strategy,
    "confidence": result.confidence,
    "execution_time_ms": result.execution_time_ms,
    "truth_confidence": result.truth_confidence,
    "emotion_style": result.emotion_style,
    "impulse_primary": result.metadata.get("impulse_primary", ""),
    "rag_used": result.rag_used,
    "health_score": result.health_score,
    "errors": result.errors,
}
```

## Тест

**Существующий тест:** `tests/test_pipeline/test_reflection.py`
- `test_reflection_success` — проверяет, что фаза не падает с ошибкой. После фикса должен проверить, что `state_manager.update` получает непустой словарь.

**Новый тест:** Добавить интеграционный тест:

```python
async def test_reflection_receives_result_dict():
    phase = ReflectionPhase()

    # Мокаем system_state_manager
    with patch("core.xray.system_state.get_system_state_manager") as mock_get:
        mock_manager = MagicMock()
        mock_get.return_value = mock_manager

        ctx = PipelineContext(
            user_message="test",
            context={
                "result_dict": {  <-- Должно быть записано executor'ом
                    "success": True,
                    "response": "test response",
                    "intent": "chat_general",
                    "strategy": "simple",
                    "confidence": 0.85,
                },
                "pipeline_success": True,
            },
        )
        result = await phase.execute(ctx)

    assert result.success
    # state_manager.update должен быть вызван с непустым словарём
    mock_manager.update.assert_called_once()
    call_dict = mock_manager.update.call_args[0][0]
    assert "success" in call_dict
    assert call_dict["response"] == "test response"
```

## Результат

| До | После |
|----|-------|
| ReflectionPhase получает пустой `{}` | ReflectionPhase получает полный PipelineResult |
| `system_state_manager.update()` не работает | Системное состояние обновляется корректно |
| Silent no-op | Reflection выполняет свою функцию |
