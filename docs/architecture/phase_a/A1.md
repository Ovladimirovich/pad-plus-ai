# A1: Fix `execution_time_ms` — Write Before Read

## Проблема

EvaluationPhase читает `ctx.context.get("execution_time_ms")`, но это значение **никогда не записывается** в context. В executor.py `execution_time_ms` вычисляется как `(time.perf_counter() - start_time) * 1000` и сохраняется только в `result.execution_time_ms`, но не в `ctx.context`.

**Файл:** `backend/core/pipeline/phases/evaluation.py`, строка ~44:
```python
"execution_time_ms": ctx.context.get("execution_time_ms"),
```
Всегда возвращает `None`.

## Причина

`PipelineExecutor.execute()` вычисляет `execution_time_ms` только в конце метода, присваивая `result.execution_time_ms`. Промежуточная запись в `ctx.context` не производится.

**Файл:** `backend/core/pipeline/executor.py`

## Решение

В `executor.py`, перед запуском цикла фаз, записать начальное значение `execution_time_ms` в `ctx.context` как `0.0`. После каждой фазы обновлять `ctx.context["execution_time_ms"]` с актуальным прошедшим временем.

### Конкретные изменения

**1. `executor.py` — в методе `execute()`, после строки:**
```python
ctx.context["call_count"] = self._call_count
```
Добавить:
```python
ctx.context["execution_time_ms"] = 0.0
```

**2. `executor.py` — в цикле фаз, после каждой успешной фазы, добавить обновление:**
```python
ctx.context["execution_time_ms"] = (time.perf_counter() - start_time) * 1000
```
(Лучше всего — в `_apply_phase_result` или сразу после `phase_result = await phase.execute(ctx)`)

## Тест

**Существующий тест:** `tests/test_pipeline/test_evaluation_phase.py`
- `test_evaluate_called_with_metadata` — проверяет, что `execution_time_ms` передаётся в evaluator. Сейчас тест проходит, потому что передаёт `None`, а не проверяет значение. После фикса тест должен получать `≥ 0`.

**Новый тест:** Добавить в `test_evaluation_phase.py`:
```python
async def test_execution_time_ms_is_written_before_evaluation(self, mock_evaluator, mock_collector):
    phase = EvaluationPhase(evaluator=mock_evaluator, collector=mock_collector)
    ctx = PipelineContext(
        user_message="вопрос",
        context={
            "response": "ответ",
            "execution_time_ms": 1500,  # Должно быть записано executor'ом
        },
    )
    await phase.execute(ctx)
    mock_evaluator.evaluate.assert_called_once()
    meta = mock_evaluator.evaluate.call_args[1]["metadata"]
    assert meta["execution_time_ms"] == 1500  # Должно быть > 0, не None
```

## Результат

| До | После |
|----|-------|
| EvaluationPhase получает `None` | EvaluationPhase получает актуальное время |
| Метрика `execution_time_ms` не работает | Метрика передаётся корректно |
| Silent no-op в evaluation | Evaluation учитывает время выполнения |
