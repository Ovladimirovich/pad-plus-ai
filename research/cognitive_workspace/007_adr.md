## Context

Phase A–C completed:
- ✅ Phase A: Architecture Cleanup (contracts, dead code, dual SOF)
- ✅ Phase B: Pipeline Stabilization (typed schemas, bg_data alignment, ContractValidator wired)
- ✅ Phase C: Session Isolation (Emotion/Impulse per-session, unified session_id)

**Problem (from 001):**
Pipeline `ctx.context` is an untyped `Dict` bag (70+ keys). No cross-turn workspace. 4 independent MetaLearners. No goal stack. No explicit reasoning trace. Session identity fractured across 5 systems.

---

## Decision

**Adopt the Composite Cognitive Workspace Architecture** composed of:

| Layer | Component | Design |
|-------|-----------|--------|
| **Turn** | `TurnWorkspace` + Custom Checkpointer (A2) | Phase-aware, typed, checkpointed |
| **Conversation** | `ConversationWorkspace` Structured Core (B2) | Topic stack, goal stack, entities, facts |
| **Working** | `WorkingScratchpad` (C2) | Evidence → Hypothesis links |
| **Memory** | Two-Tier + Conversation (D2) | Turn (PG) + Session (PG) + Vector (pgvector) |
| **Goals** | Hybrid Goal Stack (E3) | Hierarchical + suspend/resume |
| **Reflection** | Hybrid Engine (F3) | Structured always + LLM deep |
| **Planning** | LLM-as-Planner + Structured Output (G2) | Dynamic replanning |
| **Learning** | Learning Coordinator (H2) | Single source of truth |

---

## Consequences

### Positive
- ✅ **Single source of truth** per turn & conversation (eliminates ctx.context bag)
- ✅ **Type-safe contracts** — ContractValidator pre/post per phase
- ✅ **Time-travel debugging** — Load any turn at any phase (X-Ray integration)
- ✅ **Cross-turn continuity** — Topics, goals, entities persist
- ✅ **Unified learning** — One coordinator owns all learning signals
- ✅ **Session isolation** — Phase C verified, per-session stores
- ✅ **No new heavy deps** — stdlib + pydantic + asyncpg only

### Negative
- ⚠ **Implementation effort** — ~6 weeks engineering (phased)
- ⚠ **Checkpointer overhead** — Must stay < 10ms/phase (validated in PoC < 5ms)
- ⚠ **LLM planner/reflection cost** — Controlled via structured-first + throttling
- ⚠ **Schema evolution** — Additive-only policy enforced

---

## Risks & Mitigations

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Checkpointer latency > 10ms | Low | Medium | Async writes, batch phases, measure in prod |
| ConversationWorkspace growth | Medium | Medium | Summarize every 10 turns, TTL 30 days |
| LLM planner hallucination | Medium | High | Structured output + schema validation + fallback |
| Session store contention | Low | Medium | Per-session stores, no global lock |

---

## Alternatives Considered

| Alternative | Rejected Because |
|-------------|------------------|
| LangGraph checkpointer (A1) | Duplicates pipeline executor, heavy dep |
| Generative Agents memory stream (B1) | Unstructured, LLM-dependent, hard to contract-validate |
| Flat task list (E2) | No suspend/resume for multi-turn reasoning |
| Event bus learning (H1) | Eventual consistency, no single source of truth |
